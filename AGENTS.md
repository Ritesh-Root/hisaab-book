# AGENTS.md — Hisaab

Hisaab (हिसाब) reconciles a small merchant's UPI statements (PhonePe, Google Pay,
Paytm) against their sales register and reports every missing, unsettled and
duplicate rupee — with evidence, verified before publication.

## Commands

```sh
bun install          # install
bun run dev          # dev server (port 8080)
bun run build        # production build (Vite + nitro)
NITRO_PRESET=vercel bun run build  # Vercel-compatible production output
bun run test         # vitest — engine tests, must stay green
bun run lint         # eslint (0 errors required)
bun run format       # prettier
bun scripts/gen-seed.ts  # regenerate deterministic seed CSVs in public/samples/
```

## Architecture

```
UI (Workspace.tsx: empty → parsing → matching → report)
  └─ reconcileFiles  (src/server-fns/reconcile.ts — createServerFn, zod-validated)
       └─ reconcile  (src/lib/engine/pipeline.ts)
            parse (csv.ts) → normalize (normalize.ts, per-app heuristic mappers)
            → match (match.ts: UTR+amount, then amount+±10min)
            → classify (findings.ts: missing / unsettled / duplicate)
            → verify (verify.ts: THE GATE — claims dropped unless cited raw rows
              contain the claimed amount and UTR)
            → templates (templates.ts: bilingual finding text)
            → optional LLM enrichment (llm.ts, only if OPENAI_API_KEY + opts.enrich)
```

- `src/lib/hisaab/types.ts` is the FROZEN UI contract (Finding, Summary, TxRow,
  EvidenceRow). The engine outputs exactly these shapes — do not change them
  without updating Workspace.tsx and report.$id.tsx together.
- `src/lib/engine/types.ts` holds engine-internal types (CanonicalTx,
  ReconciliationResult) — safe to extend.
- Seed data in `public/samples/` is generated by `scripts/gen-seed.ts` with a
  seeded LCG — byte-identical on every run. The demo story: ₹4,200 missing
  across one missing credit (UTR ···8842), one unsettled GPay credit (···2210),
  one Paytm duplicate (···5517).

## Rules for agents working here

- **Deterministic core**: `reconcile()` with no env keys MUST produce the full
  correct result with zero external calls. The LLM layer is optional enrichment
  that degrades to templates. Never make the demo path depend on the network.
- All amounts are integer paise internally; rupee decimals only at CSV edges.
  Format with `Intl.NumberFormat("en-IN")` (see src/lib/hisaab/format.ts).
- TypeScript strict, no `any`. Every finding must cite real evidence rows
  (actual file, 1-based line number, actual raw text).
- Tests: engine tests live in `src/lib/engine/__tests__/`. New engine behavior
  gets a test in the same commit.
- Commits: conventional (`feat:`, `fix:`, `test:`, `chore:`, `docs:`), small,
  append-only history (see Lovable note above).
- Security: never commit `.env` or API keys. `OPENAI_API_KEY` is server-side
  only — it must never reach client bundles.
